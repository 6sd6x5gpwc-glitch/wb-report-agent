Политика конфиденциальности

WB Report Agent. Обновлено 29 сентября 2026 года.

Кто обрабатывает данные

WB Report Agent — персональный инструмент. Он работает только на компьютере своего владельца и используется только им самим. Приложение не предлагается другим пользователям и не имеет серверной части.

Какие данные используются

Приложение обращается к аккаунту Google самого владельца, чтобы создавать и изменять таблицы с финансовыми отчётами на его Google Диске. Запрашивается единственное разрешение — drive.file: доступ ограничен файлами, которые создало само приложение. Остальные файлы на Диске ему не видны.

Содержимое отчётов — данные продаж собственного бизнеса владельца, полученные из API Wildberries. Персональных данных покупателей приложение не получает и не обрабатывает.

Где хранятся данные

Рабочие файлы и токены доступа хранятся локально, на компьютере владельца. Отчёты хранятся в Google Таблицах его же аккаунта. Никаких других хранилищ приложение не использует.

Передача третьим лицам

Данные не передаются, не продаются и не публикуются. Обмен происходит только между компьютером владельца и сервисами Google и Wildberries, в объёме, необходимом для работы.

Аналитика и реклама

Не используются. Приложение не собирает статистику использования и не показывает рекламу.

Удаление данных и отзыв доступа

Владелец может в любой момент отозвать доступ приложения на странице Google Account → Сторонние приложения, а также удалить локальные файлы и созданные таблицы. После этого приложение теряет любой доступ к данным.
