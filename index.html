WB Report Agent

Личный инструмент для подготовки финансовых отчётов Wildberries.

Что это

Скрипт, который запускается на личном компьютере владельца. Он забирает еженедельные финансовые отчёты из API Wildberries, считает по ним прибыль, логистику, комиссию и остатки, и раскладывает результат в Google Таблицы владельца.

Зачем нужен доступ к Google

Чтобы создавать и заполнять таблицы с отчётами на Google Диске владельца. Другого назначения у доступа нет.

Политика конфиденциальности

Инструмент не является публичным сервисом и не предоставляется третьим лицам.
